# MCP server setup: RegCheck demo

This document covers how mevzuat-mcp and yargi-mcp run on this Windows PC, how they're exposed to UiPath Orchestrator as **Remote MCP servers** through Cloudflare quick tunnels, and how access is restricted with a bearer token.

```
UiPath Orchestrator ──HTTPS──▶ *.trycloudflare.com ──tunnel──▶ cloudflared.exe (this PC)
                                                                   │
                         ┌─────────────────────────────────────────┴──────────────┐
                         ▼                                                        ▼
        127.0.0.1:8101/mcp  [bearer check]                     127.0.0.1:8102/mcp  [bearer check]
        mevzuat-mcp 0.3.0 (FastMCP, streamable HTTP)           yargi-mcp 0.2.2 (FastMCP, streamable HTTP)
```

## Quick start

```powershell
cd "C:\Users\PelinYetiş\Desktop\RegCheck Demo"
powershell -ExecutionPolicy Bypass -File .\start_demo.ps1        # start servers + tunnels, prints URLs + token
powershell -ExecutionPolicy Bypass -File .\start_demo.ps1 -Stop  # stop everything
powershell -ExecutionPolicy Bypass -File .\start_demo.ps1 -NoTunnel  # local only, no public URL
```

The script prints the two public MCP URLs and the `Authorization` header. It also writes the URLs to `remote\logs\urls.json`.

> ⚠️ **Quick-tunnel URLs are random and change every time the tunnels restart**, including after a reboot or after `-Stop` then start. Each time, update both URLs in UiPath. The token stays the same until you rotate it.

## Components

| Piece | Where | Notes |
|---|---|---|
| mevzuat-mcp **0.3.0** | PyPI, run with `uvx --from mevzuat-mcp@0.3.0` | The GitHub repo is gone (404); the PyPI package is the last release. |
| yargi-mcp **0.2.2** | PyPI, run with `uvx --with "mcp<2" --from yargi-mcp@0.2.2` | `mcp<2` is required: 0.2.2 crashes on import with the mcp 2.x SDK. The upstream project moved to the paid Yargı PRO service. |
| HTTP wrapper | `remote/serve_http.py` | Imports each package's FastMCP `app` and serves FastMCP's own **streamable-HTTP** ASGI app on `127.0.0.1:<port>/mcp`, behind a bearer-token middleware. |
| Token | `secrets/mcp_token.txt` (git-ignored) | 256-bit random, URL-safe. Generated by the script if missing. |
| cloudflared **2026.10.7** | `tools/bin/cloudflared.exe` (git-ignored) | Portable binary from Cloudflare's GitHub release, SHA-256 checked (see below). |
| Starter | `start_demo.ps1` | Starts 2 servers + 2 tunnels, waits for health, prints URLs. Its PIDs go in `remote/logs/pids.json`. |
| Logs | `remote/logs/` | `mevzuat.log`, `yargi.log` (server stderr, including 401 warnings) and `tunnel-*.log`. |

### Why no stdio-to-HTTP bridge
Both servers are FastMCP servers (mevzuat on fastmcp 4.1.6, yargi on fastmcp 3.4.11), and FastMCP has a native streamable-HTTP transport. `serve_http.py` calls `app.http_app(path="/mcp", json_response=True, stateless_http=True)`:
- **`json_response=True`**: replies are plain JSON, not SSE streams. Cloudflare **quick** tunnels don't support SSE.
- **`stateless_http=True`**: no session stickiness, so a reconnect or tunnel hiccup doesn't break the client.

### Auth
- Every request except `GET /healthz` must carry `Authorization: Bearer <token>`; anything else gets **401**. The comparison is constant-time.
- **Fallback** for clients that can't set headers: append `?token=<token>` to the URL. Use this only if UiPath's form has no header field, because query strings can end up in logs.
- **Rotate the token:** delete `secrets\mcp_token.txt` and re-run `start_demo.ps1`, then update UiPath.

## UiPath Orchestrator: manual steps

These have to be done in the UiPath UI. The field names below are what to look for; verify them against your Orchestrator version.

1. Run `start_demo.ps1` and keep the PC awake and online for the whole demo.
2. Go to **Orchestrator → (your folder) → MCP Servers → Add MCP Server** and choose type **Remote**.
3. Create two servers:
   - **regcheck-mevzuat**: URL = the printed `mevzuat-mcp` URL (ends in `/mcp`)
   - **regcheck-yargi**: URL = the printed `yargi-mcp` URL
4. **Authentication:** if the form has a custom-header or bearer-token field, set `Authorization` = `Bearer <token>`. If it doesn't, use the URL with the fallback: `https://….trycloudflare.com/mcp?token=<token>`.
5. In Agent Builder, add tools from these servers, enabling **only** these two:
   - `search_within_kanun` (mevzuat)
   - `get_kvkk_document_markdown` (yargi)

   Leave `check_government_servers_health` off (removed from the agent on 2026-11-05; the report must not talk about server availability). It stays useful for the manual reachability test below.

   Leave `search_kvkk_decisions` off. It needs the paid Brave Search API, and unmodified upstream yargi-mcp would silently use the upstream author's built-in key. The agent works from a curated decision list in its system prompt instead.

Re-test at any time:
```bash
cd tools
uv run --no-project --python 3.12 --with "mcp<2" python -I mcpcall.py https://<mevzuat-host>.trycloudflare.com/mcp list
uv run --no-project --python 3.12 --with "mcp<2" python -I mcpcall.py https://<yargi-host>.trycloudflare.com/mcp call check_government_servers_health "{}"
```
`mcpcall.py` reads the token from `MCP_BEARER_TOKEN`, or from `secrets/mcp_token.txt`.
Keep `--python 3.12`. Since `coded_mcp/` pulled in a uv-managed Python 3.11, uv prefers it, and on 3.11 the `--with` overlay breaks on the "ş" in the Windows user path (`ModuleNotFoundError: mcp`).

## cloudflared install note
`winget install --id Cloudflare.cloudflared` needs an admin (UAC) prompt; on 2026-11-04 the prompt was cancelled (exit 1602). Instead, the portable binary was used:

```
https://github.com/cloudflare/cloudflared/releases/download/2026.10.7/cloudflared-windows-amd64.exe
SHA-256 2493dbc168923bb3e59e5e7716f71deced92992eea9acd6e9d74f84ac7751343
```
This checksum matches both the release notes and GitHub's asset digest. `start_demo.ps1` looks in `tools\bin\` first, then `PATH`, then the winget/MSI install locations, so a later winget install also works.

## Limits and caveats (demo-grade, not production)
- **Quick tunnels** have no uptime guarantee and a random URL. Cloudflare positions them for testing. For anything longer-lived, use a named tunnel on a Cloudflare account, which gives a fixed hostname.
- **The PC is the server.** If it sleeps, reboots or loses its network, UiPath loses the tools.
- **Single shared token**, with no per-user identity and no rate limiting. Anyone with the token can make this PC query mevzuat.gov.tr / kvkk.gov.tr through it, so share it only with the UiPath configuration.
- `check_government_servers_health` probes only Yargıtay and Bedesten, **not** kvkk.gov.tr or mevzuat.gov.tr.
- The local stdio registration used for development is unchanged and independent of this setup.
